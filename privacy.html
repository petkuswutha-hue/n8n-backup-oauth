Privacy Policy

Last updated: November 7, 2026

About this application

n8n-backup-rclone is a personal, non-commercial application used to store encrypted backups of a self-hosted n8n instance in Google Drive.

Google Drive access

The application uses rclone and Google OAuth to access the owner's Google Drive account for uploading, listing, and managing backups.

Data storage and security

Backup files are encrypted using rclone crypt before being uploaded to Google Drive. Encryption passwords remain under the control of the application owner.

Data sharing

This application is intended for personal use. It does not intentionally share backup data with other users or sell personal information.

Revoking access

The owner can revoke the application's Google account access through Google Account security settings.
